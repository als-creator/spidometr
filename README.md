# spidometr

Лёгкий CLI/TUI для замера скорости интернета на Go — аналог `speedtest-cli`
для России, где Speedtest заблокирован. Скачивание и отдача в несколько
потоков, задержка, геолокация и живой терминальный интерфейс.

## Возможности

- TUI с живыми шкалами, историей, задержкой и итоговым результатом.
- Скачивание и загрузка в несколько потоков, фиксированный буфер 64 КБ.
- Источники — крупные файлы на CDN и зеркалах, доступных из РФ.
- Задержка по времени до первого байта HTTP-ответа (медиана трёх проб).
- Геолокация по нескольким независимым провайдерам.
- Русский и английский интерфейс по системной локали и стране.
- Переключение горячих клавиш в русской/украинской раскладке.
- В пайпе, скрипте или Docker без TTY — построчный CLI-вывод.
- Пять макетов и шесть цветовых тем; выбор сохраняется между запусками.

## Технологии

| Технология | Зачем в проекте |
|---|---|
| Go 1.25+ | язык, статическая сборка и кросс-компиляция под Linux/macOS/Windows |
| `tview` + `tcell` | TUI: окна, рамки, цвета, клавиатура и перерисовка |
| `schollz/progressbar` | прогресс в построчном CLI-режиме |
| `golang.org/x/term` | определение настоящего TTY для выбора TUI или CLI |
| `net/http`, `context`, горутины | параллельные download/upload, таймауты и отмена |
| `flag`, `os/signal` | разбор флагов и корректная остановка по Ctrl+C |
| `encoding/json`, `os` | настройки, ответы API геолокации и конфиг |
| `ipwho.is`, `ip-api.com`, `ipinfo.io`, `ipapi.co` | независимые провайдеры IP/города/провайдера |
| GitHub Actions + GoReleaser | тесты и сборка релизов по тегу `v*` |
| Docker | воспроизводимый запуск без установки Go |

## Сборка

Нужен Go 1.25+.

```sh
go install github.com/als-creator/spidometr@latest
```

Или из исходников:

```sh
git clone https://github.com/als-creator/spidometr.git
cd spidometr
go build -trimpath -ldflags="-s -w" -o spidometr .
./spidometr
```

Docker:

```sh
docker build -t spidometr .
docker run --rm -it spidometr
```

## Релизы

Пуш тега `v*` запускает GitHub Actions и GoReleaser. В релиз попадают
`linux`, `macOS` и `Windows` для `amd64`/`arm64`.

- Архивы `.tar.gz`/`.zip` — бинарник вместе с `README` и `LICENSE`.
- Готовые исполняемые файлы без архива: `spidometr_<версия>_<os>_<arch>`.
  На Linux/macOS: `chmod +x spidometr_*` и запуск.
- `checksums.txt` — SHA-256 для всех файлов.

```sh
git tag v1.0.2
git push origin v1.0.2
```

## Неподписанные сборки

Релизные бинарники не подписаны Apple Developer ID и не имеют
Authenticode-подписи. Это не влияет на работу самой программы, но ОС может
показать предупреждение при первом запуске.

Перед запуском сверьте SHA-256 файла с `checksums.txt` из релиза.
Запускайте только те файлы, которые скачаны из официального релиза.

**macOS**

1. Распакуйте архив и выполните `chmod +x spidometr_*`.
2. Если Gatekeeper блокирует запуск: System Settings → Privacy & Security →
   Open Anyway.
3. Для файла, скачанного через браузер, можно снять quarantine после проверки
   контрольной суммы:

```sh
xattr -d com.apple.quarantine ./spidometr_1.0.2_darwin_arm64
```

На macOS arm64 Go ставит ad-hoc подпись, но для Gatekeeper это не заменяет
Developer ID и нотаризацию.

**Windows**

1. При предупреждении SmartScreen: More info → Run anyway.
2. В корпоративных сетях AppLocker/WDAC может блокировать неподписанный
   `.exe` полностью.
3. Проверить SHA-256 можно командой
   `certutil -hashfile spidometr_1.0.2_windows_amd64.exe SHA256`.

**Linux**

GitHub отдаёт raw-бинарник без Unix-бита выполнения, поэтому его нужно
выставить вручную:

```sh
chmod +x spidometr_1.0.2_linux_amd64
./spidometr_1.0.2_linux_amd64
```

Установить в `PATH` (если `~/.local/bin` уже добавлен в `PATH`):

```sh
install -Dm755 spidometr_1.0.2_linux_amd64 ~/.local/bin/spidometr
spidometr
```

В архиве `.tar.gz` бит выполнения уже сохранён — после `tar -xzf` бинарник
запускается сразу.

Сборка из исходников и `go install` не используют quarantine/SmartScreen:
бинарник создаётся локально.

## Флаги

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `-source` | `yandex` | ID источника |
| `-threads` | `4` | Число потоков, 1–256 |
| `-time` | `7` | Длительность каждой фазы, 1–3600 с |
| `-theme` | `classic` | ID темы |
| `-layout` | `0` | Макет, `0`–`4` (0: источник → соединение → скорость → результат) |
| `-no-upload` | выкл. | Не измерять отдачу |
| `-plain` | выкл. | Всегда построчный CLI-вывод |
| `-list` | — | Показать источники и выйти |
| `-version` | — | Показать версию и выйти |

Настройки TUI сохраняются в `~/.config/spidometr/config.json`.

## Клавиши

| Клавиша | Действие |
|---|---|
| `h` | помощь |
| `s` | выбор источника |
| `r` | заново |
| `t` | тема |
| `l` | макет |
| `p` | число потоков |
| `d` | длительность |
| `u` | вкл/выкл отдачу |
| `i` | сведения о соединении |
| `q` | выход |

В модальных окнах: `↑`/`↓` или `j`/`k`, `Enter` — выбрать, `Esc` — закрыть.
Тема применяется сразу при перемещении по списку; `Enter` сохраняет выбор,
`Esc` возвращает прежнюю.
